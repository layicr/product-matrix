产品矩阵 · 管理端

本地 SQLite：data/local.db
使用说明

数据表：顶部页签切换 products（产品）、team（团队）、partners（合作伙伴）三张表。

增删改查：右上角「+ 新增」添加记录；每行「编辑」修改、「删除」移除（删除需二次确认）。

分页：列表底部支持翻页（上一页/下一页/跳转）、切换每页条数（10/20/50/100）。

字段约定：

  • id 为主键，新增时必填；编辑时不可修改。
  • status 取值：live(已上线) / soon(即将上线) / planned(规划中) / archived(已归档)。
  • is_new、is_watched 为开关（0=否，1=是）。
  • features_zh / features_en 为 JSON 字符串（如 ["特性A","特性B"]）。
  • desc_zh / desc_en 为多行文本。
  • partners 的 logo、url 可为空。

数据存放于 data/local.db（SQLite），由 npm run db:init 按 data/schema.sql 生成。
