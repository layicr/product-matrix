## 本轮修复项

本轮全量执行暴露并修复了以下问题：

1. **详情页 500（真实缺陷）**：`getTranslations({namespace: "detail"})` 引用的 `detail` 消息命名空间缺失，访问任何产品详情页均报 `MISSING_MESSAGE`。已为 `messages/zh.json`、`messages/en.json` 补充 `detail`（back/features/launch/status/demo）键。
2. **测试断言与真实数据脱节**：E2E 断言仍引用旧数据集（30 个产品、`客户画像引擎`、数字 id `/products/3`、`共 30 张便签`）。已对齐到当前 DB 真实数据（5 个产品 p001~p005、id 为 `p00x` 格式、p003 `演唱会足迹`、`共 5 张便签`）。
3. **heading 选择器歧义（strict mode violation）**：`getByRole('heading', {name: '产品矩阵'})` 同时命中 hero h1 与产品卡 h3。已统一限定 `level: 1`。
4. **首页 popup 遮罩拦截点击**：isPopup 产品（p001）加载时自动弹出全屏遮罩且时机随 Turbopack 冷编译不定，导致“申请试用”、卡片点击等用例偶发被 `backdrop` 拦截。新增 `test/utils/block-popup.ts`，在交互类 spec 的 `beforeEach` 预埋 3 小时冷却记录使其不弹。
